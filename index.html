TEACHER NOTES

About this question bank

Scope and scoring

This is an independent percentage trainer for Foundation GCSE Mathematics, not a complete examination paper or an official Eduqas resource. All questions in the app are newly written. Difficulty labels describe this app’s progression, not examination grades.

The original six percentage skills remain. Added formats include comparison questions, percentage tables, simple interest, compound change, successive changes and multiplier selection. All methods shown use the actual displayed question data.

Numeric marking: the model is rounded to two decimal places. Every entered hundredth from model − 1.00 through model + 1.00 is accepted. For percentage answers this is ±1 percentage point. Entries with non-zero digits beyond the second decimal place must be rounded before submission. Choices are exact-match selections, not numeric input.

This tolerance is intentionally generous. For small answers, it can accept values such as zero or non-whole numbers in a counting question. The exact model answer is always shown after acceptance and exact numeric results are reported separately. This rule must not be mistaken for Eduqas examination marking. The app does not assess handwritten method marks.

Saving and privacy

Where permitted, progress and your optional name are stored only in this browser. This app sends no learner data and has no analytics. Shared computers may retain the previous learner’s saved session; discard it before starting. Saving may be unavailable with local files, private browsing or restricted storage.
